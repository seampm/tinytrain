What's inside

Every piece written by hand. No ML dependencies — just C++20, CMake, and GoogleTest.

Autograd engine src/ops.cpp

  • Dynamic computation graph, reverse-mode AD
  • 25 differentiable ops: broadcast, reductions, matmul/BMM, embedding, softmax, cross-entropy, RMSNorm, dropout, RoPE
  • Every op verified by numerical gradcheck

Neural nets + optimizers src/nn.cpp, src/optim.cpp

  • Linear, Embedding, RMSNorm modules
  • AdamW (decoupled weight decay), SGD with momentum
  • Linear warmup + cosine decay, gradient clipping

Transformer src/model.cpp

  • Llama architecture: RMSNorm, causal MHA with RoPE, SwiGLU, tied embeddings
  • Checkpoint resume: --resume, --start-step
  • Exports to safetensors + config.json

Tooling apps/

  • prepare_data: BPE-tokenize corpus to binary stream
  • train: full loop — logging, checkpointing
  • OpenMP + cache-blocked SGEMM, no BLAS

Validation

Correctness is verified three independent ways — because gradient checking alone can't catch everything.

22/22

1.8e-6

2 bugs
caught by parity that gradcheck missed

The parity check — running the same checkpoint through tinytrain and through tinyinfer — caught a scrambled attention head layout and a wrong RMSNorm mean that all 22 gradient checks passed silently. Two independent implementations agreeing to 1.8e-6 is the strongest correctness signal in the project.

Train a model

# tokenize a corpus
./build/prepare_data tokenizer.json corpus.txt train.tokens

# train a 13M Llama model
./build/train --tokens train.tokens --out run1 --steps 1500 \
    --batch-size 16 --seq-len 128 --lr 3e-4 --warmup 100 --seed 42

# the checkpoint loads directly in tinyinfer
./tinyinfer prompt "Once upon a time" --model run1/ckpt-final
